# Shreeya Pareek — Portfolio Website

A responsive, multi-page personal portfolio with a soft pink, white, and lavender theme.

## Pages
- `index.html` — Home
- `about.html` — About
- `skills.html` — Skills
- `projects.html` — Projects
- `learning.html` — Learning journey
- `contact.html` — Contact and contact-number request

## Run locally
Open the folder in VS Code. You can open `index.html` in a browser, or use the Live Server extension.

## Before publishing
1. Replace the portrait placeholder in `index.html` with your approved image.
2. Create your GitHub account and update the GitHub profile/repository links.
3. Check every social link and email address.
4. Review all wording and skills so they accurately reflect your current experience.
5. Remember that the contact-number request button opens the visitor's email app; it does not collect or send phone numbers automatically.

## Publish with GitHub Pages
1. Create a repository named `shreeya-portfolio` on GitHub.
2. Upload the contents of this folder (the HTML files, `assets` folder, and README).
3. In repository Settings → Pages, choose deploying from the `main` branch and the root folder.
4. Save and wait for GitHub Pages to publish. The site URL will appear in Settings → Pages.

This site uses Google Fonts when internet access is available; system fallbacks are included.
